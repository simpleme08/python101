# My Python Portfolio

This portfolio contains 3 practical Python projects demonstrating real-world skills:

1. **Budget Tracker**
   - Track expenses, categorize, and summarize totals
   - Uses: Lists, Dictionaries, Loops, File I/O
   - Run: `python Budget_Tracker/budget.py`

2. **Password Manager**
   - Securely store usernames and passwords in a CSV file
   - Uses: Dictionaries, Lists, Functions, File I/O
   - Run: `python Password_Manager/password_manager.py`

3. **Auto-Task Bot**
   - Add, view, complete, and delete tasks automatically
   - Uses: Loops, Functions, File I/O, Lists/Dictionaries
   - Run: `python Auto_Task_Bot/task_bot.py`

---

## Skills Demonstrated

- Python basics: variables, loops, if statements, functions  
- Data structures: Lists and Dictionaries  
- File handling: read/write CSV files  
- Console application development  
- Real-world problem solving
